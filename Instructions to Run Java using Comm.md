Instructions to Run Java using Command(cmd) Prompt



1.Enter the code in Notepad



2.Save the file with CTRL+S as Classname.java



3.Create folder in Programming M drive by creating a new folder name "Java Programs"



4.Save this file as Classname.java in this "Java Programs" folder



5.Then save this file in notepad into the folder by changing extension as .txt file to all files



6.Open Java folder in Files Explorer and click on Path and edit it as "cmd"



7.Then Command Prompt opens with Java Programs then use
"javac Classname.java" -Then click Enter(The program will be compiled if there are no errors!)



8.Then a classname.class file is created then enter
"java Classname" -The  click Enter(The output is displayed)



NOTE: The Classname and created file name created should be the same Classname.java \[with .java extension]
